## 3. Visual system (IC less-but-better)

### Palette (cool daylit, one temperature everywhere)
| Token | Hex | Job |
|-|-|-|
| Background/Day | `#EEF1F4` | Page base. Cool morning light, not spa beige, not Caliper linen |
| Surface/White | `#FFFFFF` | Photo mats, forms, clickable cards only |
| Surface/Mist | `#D8DEE5` | Soft bands (FAQ, pricing facts, secondary panels) |
| Brand/Ink | `#1A222C` | Headings, dark bands (footer, final CTA), primary button fill |
| Brand/Ink Raised | `#2A3440` | Hover on Ink buttons; raised dark cards |
| Accent/Oxide | `#4A6670` | Links, active chips, week nodes, secondary emphasis. Cool slate, not Solenne sage, not Suture coral |
| Text/Ink | `#1A222C` | Body on light |
| Text/Muted | `#5C6773` | Secondary copy |
| Text/On Ink | `#EEF1F4` | Text on Ink bands |
| Text/On Ink Muted | `#A8B2BD` | Muted on Ink |
| Border/Hairline | `#C5CCD4` | Card and field edges at low contrast; prefer transparent/low-opacity outlines |
| Fixed/White | `#FFFFFF` | Explicit white |

Machine-readable copy of this table: `brand/tokens.json` (the scripts read only that file).

Contrast rule found during packaging: `Text/Muted` on Mist is 4.3:1 (below WCAG AA). On Mist bands, secondary text is Brand/Ink at 72% (`Alpha/Ink 72`, 5.4:1). No new hue; the palette above is unchanged.

Rhythm on Home: Day hero (photo-led) → Mist contact-sheet band → Day procedures → Ink surgeon letter → Mist pricing → Day notes/FAQ → Ink consult CTA → Ink Raised footer. Same-colour neighbours share one gap (8pt rhythm).

Buttons: one primary (Ink fill / On Ink text) + one secondary (Oxide text link or hairline outline). Pill radius 999 for primary CTA only (chips match the pill); cards/images share the 12 / 16 concentric family.

### Type (≤5 sizes)
- Display / page titles: **Source Serif 4** 600/700. Reserve for H1 only (hero and page titles). Tracking slightly tight on large sizes. Fallbacks: Georgia, serif.
- UI / body: **Outfit** 400/500/600, including Home section H2s. Fallbacks: system-ui, sans-serif.
- Numerals: Outfit tabular for weeks, mm notes, prices (verify `tnum` support in Framer; if Outfit lacks it, give numerals fixed-width boxes so labels never jitter).
- Scale (fluid): H1 clamp ~48–96; H2 ~32–48; Lead 20/32; Body 17/28; Label 13 medium sentence case (no ALL-CAPS mono eyebrows). These five sizes are the whole system; card titles use Lead, big price facts use H2, the footer wordmark uses H1 size in Outfit.
- Measure: body max ~66ch. `text-wrap: balance` on headlines; `pretty` on paragraphs.
- Punctuation: real marks only (“ ” ’ – … ·). En dash for ranges (“7–10 days”, “Mon–Thu”). **No em dashes anywhere** (house rule wins over the generic IC list). No straight typewriter quotes in UI copy.

### Copy rules (Jamshid, standing; applies to Home, every page, listing, and CMS sample text)
1. **Headings:** ending periods or no periods are both fine, but **consistent within a page**. Linden choice: every page and section heading **ends with a period** (“A private sitting. A clear plan.”, “Recovery, week by week.”). A heading that is a question ends with “?”.
2. **Full sentences and paragraphs always end with a period** (or “?” / “!” when that is the sentence).
3. **Standalone descriptive text gets a period:** taglines, subtitles, tier descriptions, single-line descriptions, card summaries, captions, form helper text, success and error messages.
4. **Omit periods only on list items:** pricing feature bullets, credential chips, footer hours, fact rows (“Downtime 7–10 days”), proof lines joined with “·”.
5. **Never use emojis anywhere in UI text** (including CMS, alt text, SEO, listing).
6. Interpretation for Jamshid to veto: interactive **controls** (nav links, buttons, filter chips, week tabs, form field labels) and **proper names** (procedure names on cards, person names, the wordmark) are labels, not sentences or descriptive text, so they carry no period.

All copy lives in `brand/copy.json`, where every key is typed by these rules; `npm run check` fails on any violation.

### Surfaces and chrome
- Prefer whitespace + hairline borders over cards-on-grey. Cards only for independently clickable procedure/case tiles.
- Layered shadows only when elevation is needed (tight contact + soft ambient). No muddy fog shadows.
- One material language: flat daylit + photo mats. No glassmorphism mix.
- Icons: one outline family (Phosphor, Light weight, 20px), used only for menu open/close and FAQ plus/minus. Otherwise none.
